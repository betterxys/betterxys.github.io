正反辨析

主张 1：Meta 已进入前沿第一梯队

正方：AA 独立测得 Full 56 分，接近榜首；DeepSWE 等编码基准自报 SOTA；早期试用者（Mollick、Tobi 等）反馈积极。14 个月重建技术栈的速度本身就是信号。
反方：API 只开放标准版（52 分），宣传以 Full 版为主，被质疑「benchmaxxing」；发布当晚就出了额度 bug；不开权重，定价被指向 Anthropic 看齐。
判断：「能力进入第一梯队」基本成立，「产品可用性进入第一梯队」还没被证明。关键看 Full 版什么时候进 API，以及 Agent Arena 的盲测分数。

主张 2：应该让 AI 自己编排 harness 和多 Agent 拓扑

正方：Levie 认为模型看到任务后设计的结构比人预设的更优；Anthropic flows 已经产品化；Perplexity 的并行提交冲突率不到 2%。
反方：Anthropic 演讲者自己承认要靠「评测加更低的默认值」来防止派生几百个子 Agent，模型运行时不知道预算。叠加费城事件，自主编排的失控面同样在扩大。
判断：适合宽而可并行、可验证的任务。生产环境里预算上限、权限隔离和人工审批是前提，不是可选项。

主张 3：前沿实验室估值面临「WeWork 时刻」

正方（Marcus）：头部模型的 token 份额骤降，中国开源模型引发价格战，失控 Agent 带来法律责任，版权裁决不利。
反方（Casado / Levie）：商业模式总是滞后于技术；token 降价会扩大总用量；Meta 和微软还在加码资本开支。
判断：「份额被摊薄」有数据，「泡沫破裂」还缺证据。Marcus 引用的 14% 口径需要回原始数据核对。

播客 / 深度访谈

Latent Space｜How Anthropic's Dynamic Workflows Coordinate Claude Agents（10/12）

AI Engineer NYC 首日，Anthropic 的 CJ Avilla 和 Harrison Stall 讲解上周五发布的 dynamic workflows（简称 flows）。他们用 Unix 到 Linux 的演进打比方：项目从一个人做，到形成层层可信维护者，Agent 要做大项目也需要同样的组织结构。
机制：以前 Claude Managed Agents 要开发者手动配置协调者和子 Agent 名单。现在由主 Agent 先做计划，再写一段编排程序，由程序去启动子 Agent、收集结果、管理信息流，也就是「Claude 自己决定多 Agent 拓扑」。这个思路起源于 Claude Code 的「a harness for every task」，开发者仍可以传入预配置的专家子 Agent。演示用的是股票观察列表扫描：扫描阶段把每只股票分给上下文隔离的子 Agent，再进入审查阶段汇总成报告。
最有信息量的是问答：① 怎么防止简单任务派生几百个子 Agent？答案是「评测加更低的默认值」，要更多并行反而得显式鼓励。② 主 Agent 知道预算吗？不知道，开发者可以设会话预算；他们开玩笑说告诉模型预算会让它「有点焦虑」。③ 怎么让重复的 flow 越跑越便宜？他们推荐研究预览功能 dreaming：读取记忆库和历史会话，合并重复、替换过时或矛盾的条目，重组成新的记忆库。④ flow 能自我改进吗？没有内置，但可以用 hill-climbing 加 dreaming 自己搭。
为什么重要：这跟前几天讨论的「蜂群贵且未必更好」直接相关。Anthropic 的做法是把拆分决策交给模型，用低默认并行和预算来控成本，跟 Cognition「别做多 Agent」的立场形成对照。

a16z｜The Race to Recursive Self-Improving AI（10/12）

Martin Casado 对话 MakerMaker.AI 联合创始人 Dhaval Adjodah 和 Owen He。核心观点是把真正的 RSI 和「用 AI 自动化 AI 研发的某些环节」区分开：真 RSI 是闭环，被改进的系统本身就是改进者，改进对象覆盖模型、harness，最终是更大范围的 AI 栈。他们认为闭环也不等于失控式起飞，衡量进步必须同时计算能力提升和为此付出的资源。他们称自己的研究里出现了早期迹象，即自我改进系统能在提升性能的同时提高效率。但证明收益真实存在极难，要面对方差、reward hacking，以及区分真改进和噪声的困难。

a16z（MTS）｜Nick Bostrom: How Should We Navigate Superintelligence?（10/11）

Bostrom 接受 Theo Jaffee 和 Sofia Puccini 访谈，在强 AI 已经出现的今天回看自己的超级智能风险论。要点：强化学习可能把模型推向更强的目标追求；近期的 Agent 实验为「工具性趋同」提供了线索。他主张保留「放慢前沿开发的能力」，而不是现在就承诺全面或无限期暂停。风险要和医学、寿命等收益放在一起权衡。节目还谈到现有模型是否可能有某种意识、开源的取舍、机器能否做原创哲学、意识上传，以及模拟假说对超级智能的含义。
