官方确认已开源（Apache-2.0；离线推理）DeepSeek 开源内部推理框架 DeepInfer：生产栈公开，但范围仍是「V4.1-Flash＋特定硬件」

DeepSeek 于北京时间 10/20 约 17:30 起官宣开源 DeepInfer（GitHub：deepseek-ai/DeepInfer，Apache-2.0），并同步开源生产级 token 编解码组件 deepseek-recipe（官方称与官方 API 行为对齐）。README 写明：当前支持模型仅 DeepSeek-V4.1-Flash；硬件为 NVIDIA SM100 与 华为 Ascend 950；功能含优化内核、Attention DP／MoE EP、投机解码（DSpark）、SWA bounded replay、批不变推理、结构化输出等。明确不含完整服务所需的 KV cache 系统、VE／Prefill／Decode 分离与跨副本负载均衡——即「离线推理核心」而非一键托管平台。社交侧流传单集群日吞吐约 155T tokens、非高峰每 GPU 小时收入约 $38（观察者口径，公司未在 README 写死 GPU 型号）。开源时点紧接前日 DHS 文职机构排除 DeepSeek 公示。
限制：非旗舰新模型发布；「全面开源生产栈」≠可直接替代 vLLM／自建全栈。SM100／昇腾门槛高，社区复现与第三方测速尚未齐。运营数字多为转述／估算，勿当审计报表。

PyTorch Conference 10/20：Google 与 Meta PyTorch 团队开源 TorchTPU——面向 Google TPU 的原生 PyTorch 后端；官方叙事对比旧 PyTorch/XLA，强调 eager 优先、迁移近似 .to("cuda")→.to("tpu")，并整合 torch.compile、分布式（DTensor／FSDP 等）、与 vLLM／SGLang／TorchTitan／Ray／Hugging Face 路径。PyTorch 博客称已覆盖约 450 个 Aten ops、对约 5,000 个热门 HF 模型做过 out-of-box 验证；Google Cloud 同步宣布开源与推理引擎更新。HN frontpage 同日出现「Google open-sources TorchTPU」。

限制：多数质量／性价比对比为厂商评测与第三方转述；「最重要界面」是战略主张。实时 agent 仍依赖工具连接与 telephony 集成质量。

正反辨析

主张 1：DeepInfer 开源已让「闭源推理栈」失去护城河

正方：生产内核＋recipe 对齐 API 行为；开源社区可压低自托管成本；与 Flash 权重开放同属「全栈开源」叙事。
反方：官方自承缺 KV／拆分／负载均衡；硬件锁 SM100／昇腾；仅 V4.1-Flash——运维护城河仍在完整服务与调度。
判断：「核心引擎可复制」方向对；「托管服务已无壁垒」过早。看第三方端到端成本与稳定性，而非 GitHub star。

主张 2：Anthropic 安全草案是认真监管，而非自我优待的游说

正方：写入可阻止发布的量化阈值与法院路径，比纯自愿承诺更硬；公司确认草案存在。
反方：评估方可向实验室收费、联邦机构被剥夺自行叫停权——结构仍偏「实验室友好」；尚非立法。
判断：比「零新法」前进半步；关键看国会改写利益冲突与执法牙齿，而非新闻稿。

主张 3：语音将成为默认 AI 界面，文本／编码 agent 退居二线

正方（Mensch 等）：Voxtral 把听／说／工具闭环产品化；本地与邻近部署改善延迟与主权。
反方：企业自动化占比仍低（Foody／嘉宾）；编码／编排／harness 耐久仍是预算中心；语音评测自报成分高。
判断：「界面多元化」成立；「默认替换文本 agent」未到。看通话完成率与工具成功率，而非发布日 demo。

主张 4：TorchTPU 已实质打破「PyTorch＝GPU」绑定

正方：原生后端＋生态（vLLM／SGLang／HF）齐发；出厂覆盖数千模型的叙事降低迁移心理成本。
反方：峰值仍要 Pallas／切分／形状改造；TPU 进程模型约束未消；谷歌云商业动机明显。
判断：软件入口战胜利在望；硬件路由是否改写取决于价格／供应与社区内核成熟度。
