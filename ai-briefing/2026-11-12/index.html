官方确认产品/模型Google 发布 Gemini Decisions API 与 Gemini Decision 1：一次前向完成最多 1000 道封闭式决策

Google 官方博客（标注 Nov 11）推出 Gemini Decisions API，由新模型 gemini-decision-1 驱动，已在 Google AI Studio 的 Gemini API 上线。它针对工具选择、策略检查、模型路由、上下文打分等「有界选择」，把共享的多模态输入（文本、图像、音频、视频、PDF，最多 256K tokens）与最多 1000 道互相独立的问题一次评估，返回概率与 0–1 置信度，而不是逐 token 生成答案。

官方给出的产品数字：端到端延迟 150–250ms（模型计算中位 50–100ms，上下文至 16K 时从 1 到 100 题几乎持平）；定价 $0.10 / 百万输入 token，输出 token 不计费；同一 input 只计一次，官方称在其共用基准上比 Gemini 3.5 Flash-Lite + Interactions API 便宜近 5 倍。问题类型为 noul（是否）、choice（2–255 选项）和 score（有序量表）。

Google 内部已把它当低延迟控制平面：Notebook 用它做实时模型档位路由（官方称日常查询延迟可降约 40%）、Stitch 快速画布、Labs 的 CC 表情选择，以及 Search 里 MCP 工具的对抗检测。生态接入正在滚动：OpenRouter、LangChain、Vercel、LiteLLM、Pydantic AI、Pipecat、LiveKit、OpenCode；Google Cloud 上的 Gemini 支持「即将推出」。开放有免费试用档。

限制：这是封闭集合上的打分接口，不是通用聊天或长程智能体模型；官方自报的基准领先与「校准误差最低」有待独立复核。定价比较锚定自家 Flash-Lite，不直接等于对所有外部分类器更便宜。

官方确认开源/具身Runway 将 27B 世界动作模型 Praxis-1 以 Apache 2.0 开放权重

Runway 宣布，今年 9 月首次介绍的世界动作模型 Praxis-1「现在对所有人开放权重」。它是 27B 参数的 MoE 扩散 Transformer，同时预测视频与动作。官方称其在 NVIDIA RoboLab-120 榜上以 46.2% 成功率（1200 回合）居首，高于 FLUX 3 Action（42.9%）、Cosmos3 Nano（36.8%）和 π0.5（28.0%），并称优于所有开源权重的 VLA。

上线伙伴 Noble Machines、Standard Bots、Ultra 已分别在腿式人形、六轴工业臂和双臂仓储机器人上自有硬件运行。权重与推理/微调代码（含全量与 LoRA）以 Apache 2.0 发布，允许商用；可在 Hugging Face（原生 LeRobot）、GitHub、vLLM-Omni 获取，并提供 Reactor 托管推理。官方称可在 H100/B200、RTX 5090 / RTX PRO 6000 到机器人端的 Jetson Thor 上运行。对未见过的 Google RT-1 机器人微调后，官方称 SimplerEnv 成功率 80.0%，高于原 RT-1 策略的 52.4%。

限制：RoboLab-120 与 RT-1/SimplerEnv 数字均为官方自报，截止日期写「2026 年 11 月」，需以榜单/复现为准。开放的是单一检查点与适配工具，不等于已在多类本体上无需微调即可量产部署。9 月是模型发布，今天是权重开源。

官方确认科研模型DeepMind 发布 AlphaGenome 2：按细胞类型预测 DNA 变异如何改变基因表达

Google DeepMind 发布下一代 DNA 序列模型 AlphaGenome 2。与去年按组织批量并行预测的初代不同，它改成条件式架构：一次针对一种组织/细胞类型或状态，把该条件注入整个网络。训练数据包含超过 1.07 亿个单细胞剖面、覆盖 68 种组织（人与小鼠，兼有 bulk 与单细胞），并新增 DNA 甲基化读出。

官方关键结果：在 TenK10K（28 种原代免疫细胞）上，识别的因果变异从微调后的初代等基线的 16% 提升到约 30%，方向性基因效应从 23% 到 43%。模型还可在不重新训练的情况下，用少量新的单细胞 RNA-seq 快照条件化到未见过的细胞状态（官方举例包括 COVID-19 mRNA 疫苗激活的 T 细胞）。面向非商业研究的 API 与 Colab 教程即日起开放，商业研究为私有预览；官方预告将在 Antigravity 中提供 AlphaGenome 2 Skills。仅供研究，未批准临床或诊断用途。

限制：性能数字来自官方博客与合作方评价，不是监管批准的体外诊断工具。「接近两倍」指特定数据集上的召回，不能外推到所有疾病或所有细胞图谱。

主题 A：黄仁勋「将被罢免」——报道、措辞与空窗风险被拧成同一件事

  • 盯梢名单里反应最快的是把 WSJ 报道读成既成事实。@GaryMarcus 发「BREAKING: Nvidia is about to fire Jensen」，并转发盘后约跌 8%、以及「英伟达是否还会在下周把那 $100 亿给 Anthropic」的追问。这是评论者的外推，不是交易已取消的证据。
  • @natolambert 在更早的帖子里写下更冷静的利害：「Jensen 不再担任 CEO，对美国开源模型事业会非常非常不利。」稍后又以「大概已经在为下一件事募 $20 亿种子、投后 $1000 亿」的玩笑消化冲击——同一作者的两句话，说明市场同时在为治理风险和「黄仁勋本人仍会被资本追捧」定价。
  • 隐含分歧：一边把独董调查 + 第二条职场关系 + 盘后跌幅读成「董事会已无选择」；另一边仍停在「周三开会、官方尚未发声」。把「准备罢免」写成「已经开火」，会提前透支一个还没闭环的事件。

主题 B：Anthropic 路演——账簿很热，叙事更刺耳

  • 媒体侧的新事实是超额认购与「或成史上最大上市」。名单里批评最集中的仍不是「有没有人要股票」，而是路演承诺和治理。
  • @GaryMarcus 把 Dario 的 IPO 演讲比作「和 Elizabeth Holmes 说过的任何话一样满是胡说」，并转发「如果 Anthropic 真说了 AI 是赢家通吃，监管者应当极度担心」。这是他的定性，不是招股书原文的独立核对。
  • 隐含分歧：看好的一方把数倍订单和芯片商 $260 亿按发行价认购读成「机构用真金白银确认 $1.4T 附近仍买得下去」；批评方把同一热度读成「开价已经偏保守，好让上市后上涨，而公众股东依然买不到控制权」。两句话可以同时成立。

主题 C：Google 一天两条线——「不必生成文字的决策模型」与「看见单个细胞的基因组模型」

  • @Google 把 Decisions API 解释得很干脆：多数模型在写文本或逐步推理，但工作流往往只需要一次快速判定；Decision 1 用校准过的置信度在 150–250ms 内返回，而不是逐词作答。这是产品分类主张：把「分类器/路由器」从聊天模型里拆出来。
  • @demishassabis 与 @GoogleDeepMind、@pushmeet 同步推出 AlphaGenome 2，强调同一段 DNA 在不同细胞里被不同阅读、以及「学术 API 今天就可用」。这是科学发布，和 Decisions 的工程控制平面几乎没有争点，只是同一天里 Google 把「快决策」和「细粒度生物预测」一起铺开。
  • 本窗盯梢名单对 Qwen4 / ERNIE 预览的原创评论不多；增量信息主要来自官方账号本身，而不是二次解读。

正反辨析

正方 · 黄仁勋去职若发生，是治理底线而不是「AI 周期见顶」。爆出与情报风险相关的关系和向自己汇报的高管的第二条关系后，董事会如果不动，独立调查的公信力会先破产。股价盘后波动首先反映的是关键人风险与继任真空，不必自动等于芯片需求消失。
反方 · 在官方声明前把「即将开会」写成「已经开火」，会误导交易与供应链预期。黄仁勋高度集权、没有公开继任者，本身就是这笔报道杀伤力大的原因；也因此更需要把 WSJ 消息、国会传唤传闻、股东诉讼和「Anthropic 私募会不会变」逐条拆开。没核到的取消，就还只是猜测。

判断：把 WSJ/TC 当作高权重的公司治理风险预警是合理的；把免职当成已发生、或把盘后跌幅当成技术周期反转，都不被本窗证据支持。下一窗口应优先看英伟达是否发官方声明，而不是社交网络上的措辞升级。

正方 · Anthropic 数倍超额说明 $70–$78 的开价至少在机构账簿上走得通。芯片商按发行价认购 $260 亿、最大上市叙事、11/18–11/19 的明确时间表，把「还能不能发出去」从疑问推进到「以什么价发出去」。
反方 · 热认购不能自动证明 $1.4T 完全稀释估值已被基本面锁死。FT 的「或上调到 $1.5T」与彭博的「先开在 $1.4T 附近」互相打架；创始人套现与双层控制权、以及路演中的长期医学承诺，仍会被批评者写成治理与叙事折扣。

判断：本窗可确认的是需求信号和文件结构，不是最终定价。把「史上最大上市」写成已完成的纪录，还为时过早。
