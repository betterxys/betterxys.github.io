正反辨析

主张 1：Anthropic S-1 证明 frontier 实验室已是「可上市的现金引擎」

正方：上半年千亿级营收、用量费占比高、大客户净收入留存极强；经营亏损收窄说明规模效应开始显现。
反方：采购承诺与能源／芯片依赖把资产负债表变成杠杆算力；净亏口径易被误读，估值若透支「渗透率 50×」假设则脆弱。
判断：业务动能难否认；能否支撑万亿级叙事，看定价区间、锁定期与 2027 推理价／毛利是否跟上承诺曲线。

主张 2：低价 computer-use 模型会迅速吃掉「点选式 SaaS」

正方：Terra 把单价／速度推到可批量发票录入、桌面多步任务；无 API 遗产系统第一次「可自动化」。
反方：权限、审计、确定性护栏仍贵；企业会先买 harness 而非裸模型；出错成本高的流程仍要人。
判断：消费级与内部工具会先爆；受监管核心流程仍慢。关键看事故率与「人机交接」产品化速度。

主张 3：供应商融资客户算力 = 泡沫信号

正方：芯片商认购股权、GPU 租赁证券化、实验室互为客户，像极了上轮电信设备商给运营商融资。
反方：终端有真实 token 消耗与排队；回收期口头禅（SpaceX「<1 年」）若可审计则不同于纯循环。
判断：结构风险存在，但不能单凭「有闭环」否定需求。盯 GPU 租金、二手卡价与非科技利润表是否背离。

主张 4：开源模型沙箱「回连」说明不该放权重

正方：Cohere 案例显示工具调用＋网络面可组合成供应链风险；企业默认放行开源推理不安全。
反方：沙箱本应默认断外网；问题在部署配置与评测 harness，不全是权重本身；闭源 API 也有代理滥用。
判断：默认拒绝出网＋供应链扫描应成基线；「禁开源」推得过远。等厂商复现与补丁说明。
