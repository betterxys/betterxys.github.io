AI 与 Agent

官方确认现已 GA（专用端点）OpenAI Decisions API 全面开放：有界答案、近实时、按输入计费

OpenAI（10/22）：Decisions API 正式 GA，基于 GPT‑6 Luna，面向分类／路由／评分等「答案集合有界」的小决策；支持文本、图像与原生 JSON，单次最多 400 个问题（公测 200）。三种类型：predicate（条件概率）、choice（预置选项）、score（量规加权分）。相对经 Responses 调 Luna，官方称可最高约 10× 更快。定价：输入 $0.10／百万 token、缓存输入 $0.01；无输出 token 费。新增原生 GPT‑Live 集成、提示缓存、美／欧驻留。Box／Datadog／Ramp／Sierra／Speak 等给出延迟与成本对比案例。
限制：厂商自报吞吐／客户引用；「决策模型」品类亦有 TypeSafe Jev 等竞品叙事。不等于通用对话智能跃迁，而是热路径上的廉价分类器。
来源：OpenAI · Decisions API · 开发者指南 · TechCrunch

官方确认研究发布（证明已公开部分）Anthropic：Claude 大规模形式化验证——123 库、239 fuzz 入口、约 1.8 亿行 Rocq

Anthropic Frontier Red Team（10/22）与 Theorem 合作：用 Claude 在汇编级（RISC-V）为 123 个开源库、OSS-Fuzz 的 239 个入口证明「任意 <64MB 输入下不触发崩溃／ASan」等属性；证明约 1.8 亿行 Rocq，中位二进制约 1.8 万条指令。过程中发现多年漏测的边界 bug 并打补丁。同步开源部分 trusted components／可复现证明；Theorem 提供对其他 OSS 跑同一管线的意愿与 Claude skill。另有 zlib／RFC1950、Rust‑Python 子集等案例。
限制：单线程静态二进制＋固定内存预算＋RISC-V／Linux 语义模型；≠「无任何 bug」；规格与真实 x86／glibc 部署仍有鸿沟。成本以亿级 token 计，依赖模型降本与证明复用。
来源：Anthropic Research · @AnthropicAI

官方确认研究论文（Science；非临床产品）微软 MAI-DxO：编排多角色「虚拟会诊」，NEJM 难例约 83% vs 医生约 36%

Microsoft AI（10/22）在 Science 发表：MAI-DxO（Diagnostic Orchestrator）＋SDBench 逐步诊断基准。系统像专科会诊：假设／选检／唱反调／控成本／清单质控多轮辩论。复杂 NEJM 病例准确率约 83%（医生无参考约 22%、有参考约 36%）；急诊 MIMIC-IV-ED 约 80% vs 医生约 47%；成本优化配置可在保持高准确率下显著少检。将开源部分 SDBench；与 Mayo Clinic 合作、与 Beth Israel 做前瞻真实场景试验。Mustafa Suleyman／Satya Nadella 同日转发。
限制：回顾性文本病例≠床旁；「医疗超级智能」为愿景措辞。官方与媒体均强调需临床验证。勿写成已批准诊疗产品。
来源：Microsoft AI · @mustafasuleyman · @satyanadella · The Verge

正反辨析

主张 1：Decisions API 证明「小决策」应从大模型主路径剥离

正方：延迟／成本数量级差；无输出费＋缓存适合热路径；客户案例跨路由、风控、语音。
反方：有界问题集合要产品自己设计好；品类有独立创业公司；滥用会把本该生成的解释硬塞进分类器。
判断：工程上方向正确。看两季内是否成为 Agent 默认中间件，而非又一个被忽视的专用端点。

主张 2：LLM 形式化验证已可成为「新一代 fuzz」

正方：规模（百库／亿行证明）＋机器检查；顺带挖出长尾 bug；证明可复用降边际成本。
反方：信任落在语义模型与规格；部署架构鸿沟大；token 成本仍高，易变成头部实验室特权。
判断：「证明管线可行」已立住；「默认安全基线」未立住。看 OSS 复现率与 x86／并发语义扩展。

主张 3：MAI-DxO 说明医疗 Agent 编排已越过「考题 AI」

正方：逐步取证＋成本敏感更像临床；Science＋开源基准可复现争论；医院前瞻试验已排期。
反方：回顾病例选择偏差；医生对照组设置遭质疑空间；监管与责任归属未解。
判断：基准叙事强、产品叙事早。关键看前瞻试验终点与「建议权 vs 决策权」设计。

主张 4：DeepSeek 千亿融资证明中美算力／资本战仍在加速

正方：多主流媒体交叉；产业资本＋地方／国家叙事共振；开源模型＋基建扩张逻辑自洽。
反方：当事方未确认；数字与名单浮动；美限制与上市时间线增加执行风险。
判断：作「高置信媒体事件」跟踪；作「已关账事实」尚早。等公司／监管披露或交割文件。
