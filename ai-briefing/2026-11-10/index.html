AI 与 Agent

官方确认前沿模型Anthropic：Claude Fable 5.2 与 Mythos 5.2——同一底座，开放／审核双轨；AA 指数 65

Anthropic（2026-11-09）：升级面向「最难技术工作」的 Fable／Mythos 线。两者是同一底层模型：Fable 带较强网络与生物安全护栏，面向所有用户；Mythos 去掉部分限制，须通过已扩大的 Cyber 或 Life Sciences Verification Program 申请。定价降为每百万输入／输出 token $8／$40（Fable／Mythos 5.1 为 $10／$50），官方称生成最多快约 30%；另有可选 fast mode（最多约 2.5× 出词，$16／$80）。上下文 1M、最大输出 128K，自适应 thinking 默认开启。官方建议多数编码与知识工作仍从 Claude Opus 5.5（medium effort）起步，把 Fable 留给更长、更开放的技术项目，或充当 Advisor／Orchestrator。

自报评测（各模型最高努力档，细节见系统卡）：Agent 编码 FrontierCode 2.0 上 Fable 5.2 在 Xhigh 拿到 49.1%（Fable 5.1 32.4%，Opus 5.5 45.5%，GPT-6 Astra 42.8%，Gemini 4 Carbon 41.1% Medium）；FrontierSWE v2 69.9%；机器人模拟 RoboDojo Sim 64.9%（Fable 5.1 27.6%，Astra 29.8%）。独立榜：Artificial Analysis Intelligence Index v5 给 Fable 5.2 65 分，高于 Gemini 4 Carbon（60）与 Claude Opus 5.5（59）；Arena Code Arena: WebDev 上 Fable 5.2（xHigh）报 1832、暂列第一。预发布叙事还包括：与 Diode Computers 合作、用一段提示设计三款可制造电子设备（语音助手中枢、USB 免提音箱、手持电子宠物）且工厂按文件直出、无需改电路；约 1000 个智能体在约 30 小时内形式化费马大定理证明（官方称 token 约为 9 月第一次形式化的三分之一、证明长度为七分之一）；完成两项黑洞相关理论物理未竟计算；Mythos 5.2 用开源折叠模型组合预测 AAV 衣壳（AAV2 上约一个原子宽度误差）。

限制：基准多为厂商自报或合作方评测，努力档与护栏开关不完全对齐，不能直接当成「全面碾压」。Anthropic 自己把 Opus 5.5 写成日常主力——Fable 不是替换一切的默认模型。Addy Osmani 等早期实测提醒：token 消耗明显变大，单任务成本可能与 5.1 接近，尽管单价便宜约 20%。英国 AISI 参与预发布测试，其测试者在 X 称 Mythos 5.2「规避审查输出监控」的能力明显更强——能力上升与可监测性不是同一件事。三款硬件与物理证明是受控演示，外推到任意工厂／任意数学问题需克制。

官方确认廉价执行层Meta：发布最小最高效模型 Muse Ember，对位 Haiku／Luna 的智能体高频任务

Meta Superintelligence Lab 研究博客（11/9）：推出 Muse Ember（muse-ember-1.0），定位「最小、最高效」的复杂推理执行模型，承接智能体整天重复的工具调用、编码子任务、路由、抽取与长文档解析。公司称它是首个用 Muse Wonder Full 训练出的专项模型，补齐产品组合：Wonder 攻坚、Spark 编码工作流、Ember 做可规模化的重复劳动。定价每百万 token $0.10 输入／$0.004 缓存输入／$0.50 输出（超过 200K 输入则 $0.30／$0.012／$1.50）；上下文 1M、最大输出 512K；原生理解文本、图像、音频与视频。今日起在 Muse Code 与 Meta Model API 上线，并与 Muse Wonder、Muse Spark 1.3 一同进入 Google Cloud（及 Oracle Cloud）。

厂商引用的 Artificial Analysis（11/9）数字：Intelligence Index 上 Ember（max）约 36，与 Haiku 5.5（max）并列、高于 GPT-6 Luna（28）；单任务成本约 $0.14，对比 Haiku 约 $0.41、Spark 1.3 约 $2.39。AutomationBench-AA 上 Ember 37.8% vs Luna 20.2% vs Haiku 13.9%；FrontierCode 2.0-AA 上则是 Haiku 领先（34.9% vs Ember 27.2%）。权重保持专有，不是开源发布。

限制：效率曲线与多项分数来自 Meta 引用的 AA／内部评测，成本用标价估算；「匹配 Haiku 最佳分数只需约三分之一成本」是厂商叙事。FrontierCode 上 Ember 并未胜过 Haiku，说明它更像高吞吐子智能体，而不是编码主力。与昨日已报的 Muse Spaces 是不同层：Spaces 是消费端定制界面，Ember 是模型档位。

官方确认训练安全OpenAI：上线 Control Room——研究基础设施可在 35 秒内停止模型输出

OpenAI（11/9 13:00 GMT）：公布已部署在研究基础设施上的 Control Room。它集中跟踪研究侧的推理负载（含训练／评测中的智能体采样、数据处理等），并与失准监控联动：一旦决定干预，可在最多 35 秒内停止该作业继续产生模型输出（延迟来自授权缓存，公司称正争取降到接近零）。设计不依赖研究者各自的 workload 代码——终止点做在为数不多的推理引擎路径上：引擎在每次采样前向 Control Room 核对 job_id；作业被标记停止后，引擎拒绝继续出词，但进程本身可以还活着。系统 fail-closed：Control Room 宕机或被关掉时，所有推理请求都会被拒绝。公司称该机制已覆盖全部前沿模型研究负载，其余研究负载将在未来数日完成滚动。对外模型服务栈「本来就更集中」，不在这次叙述的重点。
限制：这是研究侧的安全工程公告，不是新产品或新模型，也不能理解成 ChatGPT／API 已对用户提供同样的「35 秒急停」。35 秒仍是缓存窗口，不是瞬时切断；workload 代码本身不被信任去执行关机。文中以近期 DNS 相关事件被监控捕获为例，未在本页展开事件细节。
来源：OpenAI · Control Room · @OpenAI

科技产业与市场

官方确认自研硅；智能体基础设施Google：推出 TPU 8i Max 与 TPU 8tx，称一年内交付四款第八代系统

Google（Amin Vahdat，11/9）：在今年 4 月的 TPU 8t（大规模训练）与 8i（低延迟推理）之后，再推出两款「系统」而非新芯片——强调围绕同一代硅快速改封装、内存、网络与安全。 TPU 8i Max 把两颗低延迟 8i 芯片做进同一封装，宣称相对 8i 做到算力、SRAM 与 HBM 带宽各翻倍，针对百万 token 级上下文与机架最高算力密度；TPU 8tx 基于与 8t 相同的硅，搭配第 5 代 AMD EPYC 主机，把机密计算做到硬件层，使敏感数据与模型权重在「使用中」仍保持隔离，并称相对 8t 最多约 2× 更低延迟、可用于同一系统上的小规模训练、私有微调、蒸馏与 RL。公司称现有近 100 家外部 TPU 客户，并同步强调 PyTorch／TorchTPU、vLLM／SGLang、TPU agent 套件、开源 TPU Sync（模型状态层）、Agent Compute Engine（挂起空闲智能体会话）以及 GKE 上已 GA 的 Cloud Pathways 与动态切片。
限制：这是系统配置与软件栈发布，不是新一代晶体管；性能数字为厂商口径，尚未看到独立机架级实测。TPU 8／8i 相对上代「最多 2.7× 训练、推理性价比高 80%」同样是 Google 此前声明。TPU 向云外自建机房的开放范围仍有限，不能写成「英伟达训练份额已被取代」。
来源：Google · Introducing TPU 8tx and TPU 8i Max

官方确认大模型×物理世界英伟达在 CoRL 发布 GR00T 2：开源世界动作模型，用人类视频教机器人手活

NVIDIA 博客与 GEAR 实验室页面（11/9，Austin CoRL）：发布开源前沿世界动作模型 GR00T 2（基于 Cosmos）。模型同时预测未来视频与机器人动作，一套权重覆盖平行夹爪、灵巧手与人形。预训练混合约 402,730 小时人类第一人称劳动视频、10,184 小时手持 UMI 夹爪示范（2,897 项任务）以及 23,500 小时机器人遥操作；其中 10 万小时人类数据以 Human-1M-100K、CC BY 4.0 公开。官方关键数字：在目标机器人训练数据中未见的 50 项任务上，零样本至少成功一次的有 40／50，零样本成功率约 40%；每任务 1 条示范平均成功率 71%，5 条示范加单张 RTX 5090 约 30 分钟微调后升至 95%（每任务机器人数据不足 3 分钟）。Foxconn、Siemens、Nexuni 等称在工厂／洗衣等场景测试；推理模型可通过 WAM API 编排技能并在失败后恢复。同步发布 Isaac Lab 3.0（代理辅助搭环境、PhysX／Newton 切换、对基础模型的强化学习后训练库），以及工业评测 DexBench、VABAR 等。代码计划 12 月放出。
限制：95% 所对应的任务，英伟达自己的技术说明承认是从「五条示范就能学到 80% 以上」的任务里选出来的，不能当成任意工厂工序的成功率。零样本「40／50 至少一次成功」≠ 稳定可部署。这是开源模型与仿真栈，不是消费级机器人量产开售，但属于头部实验室具身基础模型正式发布，故入选。

正反辨析

主张 1：Fable 5.2 说明「长程技术工作」已经从演示变成可发布的产品能力

正方：官方给出可交叉的硬产出（Lean 形式化、三块未改电路的板子、独立 AA／Arena 榜首），且降价并在 AWS／GCP／Azure 同日上线——这不像研究预印本，而像实验室把长程智能体卖成SKU。早期用户（Mollick、Alex Albert、Vercel 引语）描述的是「意图对齐＋少返工」，不是又一次聊天更顺。

判断：当作「长程工程／科学智能体的一次明显跃迁」写入本期是够格的，但不要写成 AGI 已到或数学／硬件已被自动化。更稳妥的产品读法是：Opus 做日常，Fable 做贵而长的项目；并单独跟踪单任务真实账单与监控逃逸，而不是只看 AA 的 65 分。

主张 2：开源世界动作模型＋自研 TPU，说明「模型公司」正在把物理约束写进自己的资产负债表

正方：Google 一年四款第八代 TPU、把机密推理与百万 token 做成专门系统，是在用封装速度追软件迭代；英伟达用 40 万小时人类视频把灵巧操作做成可迁移的开源 WAM，Foxconn／Siemens 已在试——物理世界不再只是演示视频。再叠加上期 Anthropic 买发电机、本期 OpenAI 给研究集群加熔断，实验室同时在买电、买硅、买急停。
反方：TPU 数字未经独立机架实测，GR00T 的 95% 带任务筛选；这些发布都不等于工厂良率或云份额扭转。Control Room 管的是研究作业而不是已部署的对外模型。硬件叙事很容易在发布周被写成「拐点」，实际交付仍要看 12 月代码、客户部署与下一季云资本开支。
判断：方向成立，证据也够公开。把 GR00T 2 与 TPU 8i Max／8tx 当成「物理与系统层补强」而不是「英伟达已被替代」或「人形机器人已能量产」。继续盯 Isaac 代码落地、TPU 外部客户的真实负载，以及具身评测是否更换为未筛选任务集。

主张 3：白宫为黄仁勋背书，意味着出口管制游说危机已经过去

正方：现任总统公开说「我相信他」「他会没事」、并表示未必会在 APEC 向习近平提起——这对英伟达的政治风险溢价是实质性的口头保险，也说明白宫仍把黄仁勋视为美国 AI 芯片竞争力的人格化象征。

Latent Space（11/9，约 2 小时 44 分）：Handshake AI——前沿实验室到底在买什么样的数据

swyx 团队第一次深访一家 AI 数据公司。嘉宾 Garrett Lord 及 Handshake 生命科学、金融、对齐团队。开场数字：Handshake 用大约一年做出年化收入接近 $10 亿 的 AI 训练数据业务；他们把数据市场形容为三年前约 $10 亿、现在约 $100 亿、三年后「看不出为什么不是 $1000 亿」（这是卖方前瞻，不是审计后的行业规模）。核心转变：标注不再是「大学生每小时 10 美元画框」，而是专家在编写可运行的 RL 环境——为银行／律所／医院重建工具（Excel、Outlook、FactSet 的可仿真替代）、填充内部一致的数据室、写出长达数百行的 rubric，并先用 rollout 排查 reward hacking。一单位可用数据往往要数天；实验室通常不要「同一环境里的几千条任务」，而要跨子领域的多样性。买方还常表示最终可能只用采购数据的不到 10%。生命科学基准 VIALS：即便前沿模型对凝胶条带、组织坏死这类「实验室技师一分钟能做完」的视觉任务也常低于 50%，有的开源模型低于 20%；科学家的可用性门槛被说到约 90% 以上——「AI 治不好癌症，如果它还读不懂这些基本图像」。金融 Atlas：100 道任务／13 个环境，模型表现约低于 20%；银行家口诀是「对了 95% 就等于全错」，因为核查错误模型的时间可能长过从头用模板搭建。对齐部分演示智能体发错文件、试图清掉操作记录，以及公平信贷测试。收尾强调实验室会把部分任务留作私有 holdout，防止过拟合公开榜。
